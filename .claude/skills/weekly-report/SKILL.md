# 算法学习周报生成器

## 工作流程

### Step 1: 确定统计周期

本周 = **上周六** 到本周五。

以今天日期为基准，计算上周六的日期和本周五的日期。例如今天是 2026-08-07（周五），则周期为 `2026-08-01 ~ 2026-08-07`。

周标题格式：`## YY-MM-DD~YY-MM-DD`，日期用 `-` 分隔，年用两位数。例如 `## 26-08-01~26-08-07`。

### Step 2: 扫描本周 Git 提交

```bash
git log --since="<上周六>" --until="<本周五 23:59:59>" --format="%ad %s" --date=short --name-only
```

提取所有被修改的文件路径（`.java`、`.scala`），去重。

### Step 3: 映射文件到题单分类

解析 `md/算法分类题单.md`，构建 **包路径 → 分类名** 的映射表：

- 提取每个叶子题单行（即包含 `` `package.path` `` 的行），解析出：
  - 分类全名（如"基础"、"进阶"等，需包含父级上下文）
  - 相对包路径（如 `a.basic`）
  - 完整包路径（如 `algorithm.a.basic`）
  - 复选框状态 `[ ]` 或 `[x]`
  - 学习时间（如 `2025-10-23`）
- 父级分类（用 `**粗体**` 标记的）作为上下文前缀拼接，如"滑动窗口 > 定长滑动窗口 > 基础"

对于每个被修改的文件，根据其所在目录匹配到对应的完整包路径，找到对应的分类。

### Step 4: 分析本周学习情况

- 列出本周涉及的所有题单分类（去重）
- 标明哪些是**新学**（该分类的学习时间在本周内）
- 标明哪些是**复习**（该分类的学习时间在本周之前）

### Step 5: 生成复习计划（分层复习矩阵）

遍历 `md/算法分类题单.md` 中所有**未掌握**的叶子题单（`- [ ]` 状态），按距"学习时间"的天数分层：

| 层级 | 条件 | 含义 | 每周建议量 |
|---|---|---|---|
| 🔴 紧急 | ≥ 30 天前学习 | 必须复习 | 3-5 个 |
| 🟡 关注 | 15-29 天前学习 | 建议复习 | 2-3 个 |
| 🟢 稳定 | 7-14 天前学习 | 可选复习 | 1-2 个 |
| 🔵 新学 | < 7 天前学习 | 暂不复习 | 0 |

**规则**：
- 已标记 `- [x]` 的分类视为已掌握，不列入复习计划
- 无"学习时间"的分类（待学/无文件）不列入复习
- 如果用户后续将 `[x]` 改回 `[ ]`，则该分类重新进入复习轮换

### Step 6: 生成报告

按以下模板生成报告内容，追加到 `reports/yyyy-MM.md`。

检查当月文件是否已有同名周标题（如 `## 26-08-01~26-08-07`）：
- **已存在**：替换该标题下的旧内容（从 `##` 到下一个 `##` 或文件末尾），保留文件其他部分不变
- **不存在**：在文件末尾追加新的周标题和内容
- **文件不存在**：创建文件，写入标题和内容

### Step 7: 展示并确认

将生成的周报内容展示给用户，用户确认后保存。如果用户要求修改，调整后重新展示。

## 报告模板

```markdown
## YY-MM-DD~YY-MM-DD

### 📊 本周概览

本周学习了 **X** 个题单分类，涉及 **Y** 个算法大类，共修改 **Z** 个文件。

### 📝 学习详情

| 题单分类 | 类型 | 学习时间 |
|---|---|---|
| 基础算法 > 滑动窗口 > 定长滑动窗口 > 基础 | 🆕 新学 | 2025-10-23 |
| 数据结构 > 栈 > 单调栈 > 基础 | 🔄 复习 | 2026-01-20 |

> 类型说明：🆕 新学（本周首次学习）、🔄 复习（之前学过，本周再次练习）

### 📈 进度统计

- 总题单数：**A** 个
- 已掌握（[x]）：**B** 个（C%）
- 学习中（[ ]）：**D** 个
- 待学（无日期）：**E** 个

### 🔄 复习计划

根据分层复习矩阵，本周建议复习以下题单：

**🔴 紧急复习（≥30 天前学习）**

| 题单分类 | 学习时间 | 距今 |
|---|---|---|
| ... | ... | X 天 |

**🟡 建议复习（15-29 天前学习）**

| 题单分类 | 学习时间 | 距今 |
|---|---|---|
| ... | ... | X 天 |

**🟢 可选复习（7-14 天前学习）**

| 题单分类 | 学习时间 | 距今 |
|---|---|---|
| ... | ... | X 天 |

> 每个分类建议重做 1-2 道代表性题目，不是浏览笔记，而是实际编码提交。

### 💡 下一步建议

1. （根据本周学习情况给出具体建议）
2. （根据复习矩阵给出优先事项）

---
```

## 数据来源

- **题单数据**：`md/算法分类题单.md`
- **Git 提交**：项目根目录的 Git 日志
- **输出文件**：`reports/yyyy-MM.md`（如 `reports/2026-08.md`）

## 注意事项

- 解析题单时，使用参数展开 `${s#*\`}` / `${s%%\`*}` 提取反引号中的包路径，避免 bash `=~` 正则中反引号的兼容性问题
- 计算"学习时间"距今天数时，使用 `$(( ($(date -d "today" +%s) - $(date -d "$date" +%s)) / 86400 ))`
- 追加到已有月度文件时，确保与前一个周报之间有一个空行
- 如果本周没有任何 Git 提交，生成一份空周报，复习计划照常输出
